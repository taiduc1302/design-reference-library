# Original UI patterns

These examples were created specifically as a starter for this library. They use **synthetic content** and no upstream copied code.

| Pattern | Preview | Main reusable ideas |
|---|---|---|
| Dashboard | [dashboard/index.html](dashboard/index.html) | Responsive shell, KPI cards, review queue, filterable table, honest example state |
| Product website | [website/index.html](website/index.html) | Editorial hero, features, responsive site layout, clear CTA |
| Presentation | [presentations/index.html](presentations/index.html) | Three-slide narrative, arrow navigation, print-to-PDF CSS |

Start a static server at the repository root: `python -m http.server 8765`. Run accessibility/visual checks before reusing any pattern in production. Adapt style and content to the specific audience and product.
